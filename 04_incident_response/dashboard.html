Packet.AI Incident Dashboard

4번 Network SRE 최종 Dashboard. 불러온 JSON 파일에 있는 값만 표시한다. 파일에 없는 값은 "제공되지 않음"으로 표시하고 만들어 채우지 않는다.

데이터 불러오기

    사례

    불러온 데이터 없음. 실제 장애 사례는 아직 진행 전이다.

    이 Dashboard가 보여 주지 않는 것

    • 실제 원인(정답)은 `incident_cases.md` 2절에만 있다. JSON으로 불러오지 않는다.
    • .pcapng를 직접 읽지 않는다. 캡처 → `summarize_pcap.py` → JSON 순서로 만든 결과만 읽는다.
    • 상태(Baseline/Fault/Recovered)는 `capture_file` 이름의 접두어(normal / fault_ / recovered_)로만 판단한다. 접두어가 없으면 "알 수 없음"이다.
